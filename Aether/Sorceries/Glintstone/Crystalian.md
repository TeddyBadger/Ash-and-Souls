### **Overview**

These sorceries are a sub type of the Glintstone sorceries, using the energy from glintstones to form more lethal, crystal-like projectiles. 

---
### **Shattering Crystal**

You fire a burst of crystals towards you in a cone of 1m reach.

|     **Info**     |   **Value**    |
| :--------------: | :------------: |
|      Damage      | 1d10 + Insight |
|   Aether Cost    |       22       |
|     Priority     |       16       |
| Attunement Slots |       1        |
| Projectile Speed |      N/A       |
|  Ticks to Cast   |       2        |
|   Action Type    |      Full      |
|  Stat Build-Up   |      N/A       |

### **Crystal Torrent**

You release a barrage of crystal shards in front of you with a maximum range of 3m. Can be held to prolong the release.
