### **Overview**

These incantations are a sub type of Golden Order incantations: they use the healing power from The Great Arborea that looms over the land of Yarven.

---
### **Urgent Heal**

Heal yourself for a small amount of HP but can be carried out quickly.

|     **Info**     |   **Value**   |
| :--------------: | :-----------: |
|     Healing      | 1d4 + Resolve |
|   Aether Cost    |      13       |
|     Priority     |      18       |
| Attunement Slots |       1       |
| Projectile Speed |      N/A      |
|  Ticks to Cast   |       1       |
|   Action Type    |     Half      |

### **Minor Arborea**

Create a small Arborea at your feet that remains there for "caster's Resolve" amount of rounds. Anyone within a 4m radius of the small Arborea, enemies included, will be healed 1d4 + "Resolve of whoever is being healed" at the start of every round.

|     **Info**     |         **Value**          |
| :--------------: | :------------------------: |
|     Healing      | 1d6 + Resolve<br>per round |
|   Aether Cost    |             25             |
|     Priority     |             17             |
| Attunement Slots |             1              |
| Projectile Speed |            N/A             |
|  Ticks to Cast   |             2              |
|   Action Type    |            Full            |
