### **Overview**

These incantations use the worship of the Ancient Dragons to conjure lightning in different forms, allowing the user to be versatile.

---
### **Electrify Armament**

Applies lightning to the weapon in your other hand, or can be cast onto another persons weapon at the cost of 2 further ticks. This changes the damage type dealt to lightning and allows the attacker to add "Resolve" to the damage they deal.

|     **Info**     | **Value** |
| :--------------: | :-------: |
|      Damage      | + Resolve |
|   Aether Cost    |    11     |
|     Priority     |    17     |
| Attunement Slots |     1     |
| Projectile Speed |    N/A    |
|  Ticks to Cast   |  1 or 3   |
|   Action Type    |   Half    |
|  Stat Build-Up   |    N/A    |
|   Damage Type    | Lightning |
|   Poise Damage   |    N/A    |

### **Vorlan's Dragonbolt**

Call down lightning to strike you or an ally, charging the target's body to provide buffs: this applied red lightning to the target's weapon and also gives them 2 temporary DR to all forms of damage. The red lightning allows the user to add an extra 1d4 and Resolve to their attacks with the enhanced weapon. This lasts "Resolve" amount of turns. To buff an ally with this effect, you must use 2 more ticks to cast.
